### 🚀 Projeto em destaque

#### [Rise Cooler Installer](https://github.com/Handerson-Henri/rise-cooler-installer)

Instalador automático não oficial do driver do display do **Air Cooler Rise Mode Temp 6 Pro** para distribuições baseadas em Ubuntu/Debian, testado no **Zorin OS**.

- Detecta automaticamente CPUs **AMD** e **Intel**
- Configura o serviço **systemd**
- Automatiza dependências e sensores
- Mantém registro do processo de instalação para auditoria
